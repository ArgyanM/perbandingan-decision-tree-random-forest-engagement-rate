# Perbandingan Decision Tree Regression dan Random Forest Regression untuk Prediksi Engagement Rate Video YouTube

Repository ini berisi kode program penelitian untuk membandingkan kinerja Decision Tree Regression dan Random Forest Regression dalam memprediksi engagement rate video YouTube.

## Variabel Penelitian

### Variabel Prediktor
- `title_length`
- `publish_hour`
- `video_age`

### Variabel Target
- `engagement_rate`

## Tahapan Penelitian

1. Preprocessing data
2. Pembentukan engagement rate
3. Feature engineering
4. Pembagian data training dan testing
5. Hyperparameter tuning Decision Tree Regression
6. Hyperparameter tuning Random Forest Regression
7. Pembentukan model
8. Prediksi
9. Evaluasi menggunakan MAE, MSE, RMSE, MAPE, dan R²
10. Perbandingan kinerja kedua model
